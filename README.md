# NxtBiz

NxtBiz is a role-aware business operations console for customer management, email intelligence, agent orchestration, workflows, tickets, invoices, reports, and live operational notifications.

## Run locally

1. Copy `server/.env.example` to `server/.env` and set the required secrets and MongoDB URI.
2. Run `npm run install:all`.
3. Seed data with `npm --prefix server run seed`.
4. Start the API with `npm --prefix server run dev` and client with `npm --prefix client run dev`.

The local demo account is `admin@nxtbiz.local` / `Admin12345`.
